### What I've done
- 🚀 Fixed a production Kafka consumer bottleneck: **1000x throughput** (~25 → ~25,000 messages/s)
- 🗄️ Ran ClickHouse in production across terabytes of data: schema design, query tuning and 2-replica high availability
- 🏛️ Led the architecture of a multi-terabyte on-prem government lakehouse with **~200 Airflow DAGs** across 7+ source systems
- 💸 Built 12 dbt ELT pipelines that replaced a manual financial reconciliation process, with invoicing data reconciled against bank records
- ⚙️ Built a generic Python ETL framework: 60% faster deployment, pipeline runtime cut from 10 to 5 hours
